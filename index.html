Part 1 — What this app does

  • Recharge: add money to play.
  • Redeem: cash out when allowed.
  • Transfer: move money between your game accounts.
  • Reset password: get a new game password.
  • Activity: see status of your requests.

Part 2 — Bottom menu

Home Recharge, Redeem, Transfer, Reset password.
Rewards Daily rewards, referrals, offers, promo codes.
Play Your game accounts and add-game options.
Activity Pending, completed, or rejected requests.
Profile Your account details and settings.

Part 3 — Recharge (add money)

  1. Tap Recharge.
  2. Enter amount.
  3. Select one game account.
  4. Select payment method.
  5. Review and tap Confirm.
  6. If you see waiting, do not pay yet.
  7. Pay only when details/timer appear.
  8. Upload proof if asked.
  9. Track status in Activity.
Tip: Check game and amount before paying. If timer ends, create a new request.

Part 4 — Redeem (cash out)

  1. Tap Redeem.
  2. Pick game account.
  3. Enter amount (and tip if asked).
  4. Choose payout method.
  5. Review and confirm.
  6. Check status in Activity.

Part 5 — Transfer

  1. Tap Transfer.
  2. Select from-account and to-account.
  3. Enter amount and confirm.
  4. Check status in Activity.

Part 6 — Reset password

  1. Tap Reset password.
  2. Pick the game account.
  3. Follow steps and save the new password.
  4. Check Activity if needed.

Part 7 — Rewards

  • Daily reward: tap Claim when available.
  • Referral: share your invite code/link.
  • Reward wallet: bonus may stay in wallet first.
  • Offers: check min deposit, bonus %, and end time.
  • Promo code: enter code and tap Apply.

Part 8 — Add rewards to game

You can move reward wallet money to game only when both rules pass:

  • You have at least 5 completed deposits.
  • Your latest completed deposit is within 14 days.
If blocked: complete a normal recharge, then try again. If still blocked, contact support.

Part 9 — Play (games)

  1. Tap Play.
  2. See linked accounts in My games.
  3. Add a game if your app allows it.

Part 10 — Activity

  • Pending: still processing.
  • Completed: done.
  • Rejected: not approved; read reason.

Part 11 — Profile

Manage name, email, password, and security options.

Part 12 — Support

Contact support if waiting is too long, timer ended, money is missing, or a message is unclear.

Send: what you tapped, what you see now, and a screenshot.

Part 14 — Quick FAQ

Stuck on waiting?

Check Activity first, then contact Support if it takes too long.

Timer ended?

Usually create a new recharge. If you already paid, send proof to Support.

Wrong game selected?

Fix before payment. If already paid, contact Support.

Bonus missing?

Check Rewards and Activity. Some bonuses need approval or completed deposit.

Part 15 — Revival bonus (simple)

Revival bonus is a comeback bonus. It may apply when a player is inactive for the required days and then makes a new deposit.

  • Inactivity check uses last activity (recharge, redeem, or extras).
  • The inactivity window is usually around 14 days, but each team can set its own rule.
  • The comeback deposit must meet minimum amount rules.
  • If eligible, revival can be used instead of signup bonus for that deposit.

Important timing

Step 1: Request created The system can record the revival event when the recharge request is created.
Step 2: Deposit completed Deposit counters move only after that recharge is completed.
Easy way to remember: revival can be marked early, but counting uses completed deposits.

After revival

  • For reward unlock counting, deposits are counted from the revival comeback point (fresh start).
  • If the player cashes out/transfer later, normal bonus restrictions can apply again.
